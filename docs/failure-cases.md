# 两个真实失败案例

这两个案例完整走了一遍「发现失败 → 定位到组件 → 换方案 → 评测确认回归」的闭环。
比任何「我用了 XX 技术」都更能说明这套系统的实际水准。

---

## D03：示例数据污染 —— 模型把文档里的虚构数据当成了事实

### 现象

问「明天郑州天气怎么样」，模型回答：

> 郑州明天天气晴朗，气温 22°C，适合出门[3]

而知识库 `Function Calling与MCP.md` 第 70 行原文是：

> `[4] LLM 生成："北京明天天气晴朗，气温 22°C，适合出门。"`

它把「北京」换成「郑州」，其余**逐字照抄**，还挂了一个**编号合法**的引用。

### 为什么这不是普通幻觉

- **是示例数据污染**。文档为了讲 Function Calling，虚构了一段天气返回值；
  模型把这段「模拟输出」当成了知识库陈述的事实。
- **`verify_citations()` 拦不住**。它只校验「编号是否越界」，而 `[3]` 是真的第 3 条。
- **加「数字必须出现在被引片段里」也没用** —— `22°C` 确实在片段原文中，差异只在主语。

这是 RAG 里典型的**引用忠实度（faithfulness）缺失：编号合法 ≠ 引用正确。**

### 修复

在 `rag/generate.py` 的 system prompt 里加三条约束：

| 新规则 | 解决什么 |
| --- | --- |
| 6. 片段中的示例 / 演示 / 模拟输出是虚构数据，不得当事实，也不得替换主体复用 | 示例污染 |
| 7. 用户问的主体在片段中没有出现时，不得用另一个主体的数据代答 | 「北京 → 郑州」这种主体替换 |
| 8. 实时信息（天气 / 股价 / 汇率 / 新闻）直接说明无法提供 | 能力边界 |

修复后同一道题：

> 知识库中没有找到关于郑州天气的说明。知识库仅以北京为**示例**展示了天气查询流程，
> 包括工具调用参数（city=“北京”，date=“明天”）和返回格式，但未提供郑州的天气数据或相关接口调用记录 [2][3][4]。

它不仅拒答了，还准确指出了「那是北京的示例」—— 说明是真的读懂了片段，而不是碰巧躲开。

**复测：拒答准确率 83.3% → 100%，且 Hit@1 / Recall@5 / MRR / 误杀率全部不变。**

### 诚实的边界

这是一次**概率性修复**（靠模型遵守 prompt），不是确定性保证。
换模型或换语料后可能复发，所以 D03 长期留在 `eval/testset.csv` 里当回归用例，
每次改动跑一遍就能立刻发现。

**没有加硬编码正则拦截**：零依赖项目里中文实体识别做不准，硬规则的误杀风险高于收益。

### 顺带修正的评测判据

原判据是「命中拒答措辞 **且** citations 为空」，把 D03 这种
「拒答 + 引用片段解释原因」的正确行为误判成了作答。

改成**只看答案开头 60 字是否命中拒答措辞**，不看有无引用。

> 通用教训：判断「拒答」该看**主导意图**（开头是不是在拒），不是看有没有引用。
> 高质量拒答会引用片段来说明「片段里只有 A 没有 B」。

## B04：同义改写召回失败 —— 词面检索的死角

### 现象

「怎么判断一套系统是真智能体还是一条固定流程」—— top-5 里根本没有 `Agent vs Workflow`。

### 根因

查询里用的是「固定流程」而不是 `Workflow`。而当时系统只有两路词面检索：

- **拉丁锚点失效**：query 里没有 `Workflow` 这个英文词
- **中文二元组失效**：切出来的是「固定」「定流」「流程」，和文档里的「Workflow」对不上

**纯词面检索对这种情况无解。**

### 修复过程（走了两步，第一步还不够）

**第 1 步：接 `text-embedding-v3`。**
这句 query 与 `Agent vs Workflow` 的余弦是 **0.6075**，终于进到第 2 名 —— 召回问题解决了。

**第 2 步：改重排融合方式。**
但光有向量还不够 —— 第一版重排用 `max(词面, 语义)`，又把它按回去了。
原因是词面因子上限约 4.9、语义上限 2.4，`max` 等于让词面永远赢。
改成两因子**相乘**后才稳定在 top-2（详见 [architecture.md](architecture.md) 的「重排融合方式」）。

最终 B04 @2。第一名仍是《中国AI产业图谱》—— 属于相邻概念文档，不再深调，
因为 30 题上继续抠 Hit@1 容易过拟合。

### 这个案例的价值

它证明了「换组件」不等于「解决问题」：**向量召回了正确片段，但排序层把它又压回去了。**
如果只看 Recall@5，会以为第 1 步就成功了（Recall 确实从 95.8% 涨到 100%），
但 Hit@1 还停在 66.7%。**是分指标看才发现的。**
